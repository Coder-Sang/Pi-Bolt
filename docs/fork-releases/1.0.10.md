# 1.0.9.a

First Linux x64 fork release for `Coder-Sang/Pi-Bolt`, based on Pi 1.4.0.
The GitHub display title is `1.0.9.a`; the tag and executable version remain `bolt-v1.0.10` and `1.0.10` for installation
and update compatibility.

- RPC `message_id` correlation with ordered queue admission, actual consumption and clearing events.
- Linux x64 default, baseline and JIT archives, tested after unpacking with a loopback-only model provider.
- Fork-specific installation/update endpoints and a dedicated release signing key.
- A pinned upstream runtime with its independent signature, checksums, version and engine-stamp validation.

The release verifies the fork signatures and pinned upstream runtime provenance. Real-provider and interactive model
smoke tests have not run. On 2026-11-05 the maintainer explicitly accepted these validation gaps and publication without
the planned release reviewers, deployment-branch restriction and branch/tag protections for this release. These accepted
limitations do not disable cryptographic signature, source-commit, clean-tree or payload-integrity checks.

The existing `bolt-v1.9.0-message` is an unsigned test prerelease with package version 1.0.9 and is retained separately.
