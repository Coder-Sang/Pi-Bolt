# Pi-Bolt 1.1.5 Message ID build 1

Linux x64 Message ID build of `Coder-Sang/Pi-Bolt`, based on upstream Pi-Bolt `bolt-v1.1.5` at
`ae783ad34109200d710fe928c5bd5c6f69fe7217`, including Pi `1.5.0`.

- Retains the optional RPC `message_id`, independently of command IDs, and version 1 `queue_update.tracking`:
  ordered admission, actual consumption batches and clearing, including initial prompts and continue paths.
- Message IDs and queue tracking stay outside model requests and persisted sessions. A consumption batch records input
  handoff, not completion of an assistant response. Abort retains unconsumed input until explicitly cleared.
- Includes upstream changes through 1.1.5: live subagent streams, remote-control session fixes, lower batch memory,
  faster extension startup, reduced command-output memory, and clean RPC stdout.
- Uses the rebuilt 1.1.5 runtime, pinned by checksum, independent upstream signature and GitHub build provenance.
  Fork download endpoints and the existing fork release public key remain unchanged.

The tag and internal version are `bolt-v1.1.5` and `1.1.5`. `build 1` is a display label. This is a prerelease and does
not replace the stable `latest` release. Use the installer attached to this fork's release:

```sh
PIBOLT_VERSION=bolt-v1.1.5 sh install.sh
```

The beta update channel also selects numeric prereleases. No npm package is published by this workflow.

Release validation and any explicitly accepted limits must be recorded here before publication.
